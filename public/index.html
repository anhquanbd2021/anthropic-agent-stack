Tier Router · cheapest-sufficient model routing

The flagship model is a routing decision, not a default.

Run a task queue through a three-tier model ladder — volume (Haiku-class), balanced (Sonnet-class), judgment (Opus-class) — with a self-check after every attempt. Watch cheap-first routing hold quality while the always-flagship baseline burns budget, and watch unverified cheap routing quietly ship wrong answers.

Safe educational demo. Mock models, deterministic checks, illustrative cost units — no API calls, no real models, nothing leaves your browser.
